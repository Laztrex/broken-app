# Оптимизации в broken-app

## Исправленные баги
- `sum_even`: устранён out-of-bounds замена unsafe-доступа на итератор.
- `leak_buffer`: добавлено освобождение памяти (Box::from_raw).
- `normalize`: теперь удаляются все пробелы (split_whitespace).
- `average_positive`: исправлена логика (усреднение только положительных).
- `race_increment`: исправлена гонка данных (AtomicU64).

## Оптимизации алгоритмов
- `slow_fib`: экспоненциальная рекурсия → итеративный O(n). Ускорение ~44 000x.
- `slow_dedup`: квадратичный поиск → линейный через HashSet. Ускорение ~10x.
